# Random numbers

Generate secure random integers in an inclusive range, with optional unique results.

Use the generated forms in Robbi V2 App library, or ask Robbi using the example phrases. Its implementation travels inside this project; it requires only the declared Robbi SDK and no provider keys or network connection.

Both endpoints are included. Maximum 100 numbers and bounds from -1 trillion to 1 trillion. Unique draws fail if there are fewer available integers than requested.
