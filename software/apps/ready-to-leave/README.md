# Ready to Leave

Configure Google Calendar, Weather and Google Maps in their own apps. Grant this
app Saved app data and Read other apps, plus each target's existing permissions.
No OAuth credentials are copied. Save an origin, travel time, buffer and carry
items in Preferences. Plan a uniquely matching calendar appointment or select an
event ID from the returned choices. Date boundaries can narrow a large calendar.

Manual travel minutes plus a directions link work without a Maps API key. An
optional route estimate uses the configured Google Routes API and may incur
charges; driving estimates exclude live traffic. Missing weather or route data is
reported explicitly. A directions link alone never supplies a travel duration.

The last three plans remain available in Preferences. Start a reminder only with
one exact plan ID; the saved departure must be within the next 24 hours. The tool
can also cancel that exact timer. Robbi's Kitchen timers list shows the actual
timer. An uncertain start is reserved and cannot be automatically repeated. State
and confirmed timer changes have the normal app undo receipts.
