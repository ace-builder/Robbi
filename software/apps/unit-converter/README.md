# Everyday unit converter

Convert physical quantities, temperatures, durations and decimal or binary data sizes.

Use the generated forms in Robbi V2 App library, or ask Robbi using the example phrases. Its implementation travels inside this project; it requires only the declared Robbi SDK and no provider keys or network connection.

Categories: length, mass, volume, speed, temperature, duration, data, area, pressure and energy. Exact unit symbols are case sensitive. Days are fixed 24-hour durations and weeks seven days, not calendar intervals. kcal uses the thermochemical calorie (4184 J). Mass-to-volume conversion needs density and is rejected. Temperatures below absolute zero are rejected.
