# Recipe portions

Scale ingredient quantities from original portions to the portions you need.

Use the generated forms in Robbi V2 App library, or ask Robbi using the example phrases. Its implementation travels inside this project; it requires only the declared Robbi SDK and no provider keys or network connection.

Up to 30 structured ingredient rows. Input amounts must be numeric (for example, 0.5 instead of 1/2). Units are preserved as labels, with results rounded to eight decimal places. Cooking time, temperature and seasoning do not necessarily scale linearly.
