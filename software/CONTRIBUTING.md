# Contributions

Discuss changes before submitting a large patch. Keep credentials, personal conversations, memories, camera photos, voice enrollment, recordings and generated runtime data out of commits. Add reusable apps under `software/apps/`; use the existing robot SDK and permission system.

The project has non-commercial terms and may offer commercial licensing separately. Do not assume a pull request grants commercial relicensing rights: arrange any necessary contributor permission with the maintainer before code is accepted. Keep third-party notices and identify the origin of new media.

Use `software/` as the Python working directory. Tests use synthetic hardware and mocked providers; do not run physical motor tests or billable API calls automatically. Follow `software/docs/development/RELEASING.md` when preparing a new snapshot.
